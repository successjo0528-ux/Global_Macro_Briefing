# 📈 글로벌 매크로 & 경제 모닝 브리핑 (Global Macro Briefing)

매일 아침 글로벌 8대 핵심 거시경제 지표와 해외 유력 매체의 경제 뉴스를 한국어로 번역 및 요약하여 제공하는 모닝 브리핑 대시보드 웹앱입니다.

---

## 🌟 주요 기능

1. **📊 글로벌 거시·외환·증시 19대 핵심 지표 (Market Tickers)**
   * 미국 단기 국채(13주), 10년물 국채 금리(신호등 뱃지), 30년물 국채 금리
   * 달러 인덱스(DXY), 달러/엔 환율, 국제 금 시세, 국제 유가(WTI), 비트코인
   * 미 재무부 TGA 현금 잔고 (공식 FiscalData API 연동)
   * 미국 증시: S&P 500, 나스닥 100, 필라델피아 반도체, VIX 공포지수
   * 한국 금융: 달러/원 환율 (1년/3년 동적 이동평균선 연동), 코스피, 코스닥, 국고채 3년/10년, MSCI 한국 ETF

2. **📰 6대 핵심 테마 분류 및 스마트 클러스터링**
   * 🏛️ **연준 정책 & 유동성**: FOMC, 베이지북, 파월 연설문, 뉴욕 연은 연구, QT, 역레포(RRP)
   * 🇺🇸 **미국 경제 & 부채**: 골드만/모건스탠리 월가 리서치, IMF/BIS, 부채 40조, 베센트 QRA
   * 🇰🇷 **외국인 수급 & 환율**: 달러/원 외환시장, 외국인 선물/주식 순매수, 외환보유액
   * 📈 **국내 거시 경제**: 한은 금통위, 한국 잠재성장률, 부동산 PF/가계부채, 수출입
   * 🤖 **AI 패권 & 반도체·전력망**: GPU/HBM, 데이터센터 전력망, SMR 원전, 핵심광물/희토류
   * 📰 **언론사 다양성 쿼터제 & 동일 이슈 타 언론사 보도 묶음 제공**

3. **🌐 스마트 한국어 번역 & 원클릭 브라우저 번역 연동**
   * 영문 기사 제목 및 본문 핵심 내용을 명확한 한국어로 번역/요약 제공
   * `[🌐 한글 번역본]` 버튼: 구글 웹 번역을 통해 브라우저에서 한국어로 번역된 원문 웹페이지 즉시 열람
   * `[🔗 원문]` 버튼: 언론사 공식 웹사이트 원문 바로가기
   * `[❤️ 즐겨찾기]` 기능: 보관하고 싶은 기사 요약을 브라우저 로컬 저장소에 영구 보관

4. **⚡ 완전 자동화 배포 및 로컬 지원**
   * **cron-job.org & GitHub Actions**: 매일 아침 **05:00 KST** (20:00 UTC) 외부 Webhook 기반 100% 정시 자동 수집 및 커밋/푸시
   * **GitHub Pages**: 모바일 스마트폰/PC 반응형 웹 SPA 지원
   * **Tool Dashboard & run.bat 연동**: 원클릭 로컬 실행 및 원격 데이터 자동 동기화(`git pull`)

## 🚀 실행 및 갱신 방법
 
### 1. 매일 아침 자동 갱신 (기본 동작)
* **cron-job.org + GitHub Actions**: 매일 아침 **05:00 KST** (20:00 UTC)에 클라우드 서버가 자동으로 19대 지표와 주요 외신/국내 뉴스를 수집/번역하여 배포합니다. (서버 큐 대기열 지연 없는 즉시 실행 체계)
* 별도의 조작 없이도 스마트폰이나 PC 웹 브라우저(GitHub Pages)에서 항상 최신 브리핑을 열람할 수 있습니다.

### 2. 스마트폰 / 웹에서 즉시 원격 갱신 (PC 불필요)
* 웹 대시보드 상단 우측의 **`[⚡ 원격 즉시 갱신]`** 버튼 클릭
* 또는 GitHub 저장소 접속 ➔ **[Actions]** ➔ **`Daily Global Macro Crawler & Auto Deploy`** ➔ **[Run workflow]** 클릭
* 약 1분 후 최신 데이터로 배포 완료

### 3. 내 PC에서 로컬 실행 및 갱신
* **로컬 대시보드 열기**: `run.bat` 실행 ➔ `4`번(최신 원격 데이터 동기화) 또는 `1`번(로컬 즉시 크롤링) 선택
* **로컬 즉시 크롤링 직접 실행**:
```bash
python crawler_runner.py
```
